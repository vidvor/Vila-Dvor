# Vila-Dvor
Vila Dvor je privatni starački dom koji svojim korisnicima nudi vrhusku profesionalnu negu i kvalitetan smeštaj.

# Dom za stare Beograd

Dobrodošli na moj GitHub profil. Bavim se optimizacijom i tehničkim održavanjem platformi za pružanje medicinske nege i smeštaja starih lica u Srbiji.

Trenutno vodim SEO projekat za [Starački dom u Beogradu](https://www.viladvor.rs), sa fokusom na poboljšanje vidljivosti usluga kao što su medicinska nega, luksuzni smeštaj za penzionere i palijativno zbrinjavanje.
